# Screenshot placeholders

Dashboard screenshots are intentionally not committed yet because the UI is generated from local run artifacts. After running `scripts/e2e-smoke.sh`, open `griddyn serve --run <run-dir>` and capture:

1. KPI cards and net-grid chart.
2. BESS dispatch chart.
3. Deferred-work queue/timeline.

Keep images small and derived from the committed tiny fixture unless a PR explicitly adds larger visual assets.
